# Changelog

## 0.1.0 — local candidate

Initial provider-neutral release: strict frozen tasks, authenticated Unix broker,
immutable run and result identities, local and private Task Spooler executors,
PySCF/ORCA/Molpro plugin interfaces, GitHub Issue/Action gateway, MCP transport,
optional OpenAI/Anthropic/Gemini clients, verified result publication receipts,
read-only legacy references, and independent synthetic demo plugin.

This candidate has not been published or installed on an existing production site.
See `docs/v0.1-acceptance.md` for actual validation and remaining compatibility gaps.
