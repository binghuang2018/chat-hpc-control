# Changelog

## 0.1.0 — 2026-10-23

Initial provider-neutral release: strict frozen tasks, authenticated Unix broker,
immutable run and result identities, local and private Task Spooler executors,
PySCF/ORCA/Molpro plugin interfaces, GitHub Issue/Action gateway, MCP transport,
optional OpenAI/Anthropic/Gemini clients, verified result publication receipts,
read-only legacy references, and independent synthetic demo plugin.

Published on [GitHub Releases](https://github.com/binghuang2018/chat-hpc-control/releases/tag/v0.1.0)
with the original accepted wheel/sdist bytes, checksums and acceptance records.
See `docs/v0.1.0-publication.md` for public CI/readback evidence and
`docs/v0.1-acceptance.md` for the original build validation and compatibility gaps.
Existing production sites were not connected or modified; no PyPI publication was performed.
