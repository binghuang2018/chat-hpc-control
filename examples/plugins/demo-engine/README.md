# chat-hpc-demo-engine

Independent example plugin for chat-hpc-control 0.1.0. It demonstrates installed
entry-point discovery, validation, native worker submission and result collection
without modifying the core package. It runs a synthetic Python input; reported
values have no scientific meaning.

Install with the matching core wheel, then use `chat-hpc-control demo --root` with
a new private Linux x86_64 site. See the core quickstart and plugin developer guide.

This newly authored example is licensed under Apache-2.0. No QC software, private
inputs, credentials or production configuration is bundled.
