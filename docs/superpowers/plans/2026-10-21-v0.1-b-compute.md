# v0.1 B：引擎、执行器与结果 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在独立 Linux 测试站点完成持久原生执行、可扩展 QC 引擎和按声明核查的不可变结果。

**Architecture:** entry point 发现不导入插件；受控清洁工作进程调用 EnginePlugin。核心批准固定执行计划后由 local/Task Spooler 运行；独立 reconciler 观察、收集并发布结果事件。

**Tech Stack:** A 阶段核心、Python subprocess/importlib.metadata、Linux `/proc`、Task Spooler 可选、pytest；QC 软件作为外部安装，不进入分发包。

**Spec:** [架构 §4–8](../specs/2026-10-21-chat-hpc-control-v0.1-design.md)、[插件协议 §4–7](../../plugin-protocol-v1.md)、[总计划](2026-10-21-v0.1-implementation.md)。

## Global Constraints

完整继承总计划。插件 API `1.0`；`walltime_seconds: null` 不设置计算超时；`data_ready` 仅由 `COMPLETED + VERIFIED + COMPLETE` 推导。所有测试站点采用独立临时根和 queue socket，不连接 n008。

## Review Focus

采用总计划五项风险。B1/B2 验证输入边界及 worker 环境，B2/B3 验证真实执行不确定性，B5 验证结果原始证据和分页固定身份。仅有正常退出码不能满足数值完整性。
